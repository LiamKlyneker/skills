# Session messages — what Liam types to an agent

Messages Liam typed by hand to an agent in a Claude Code session, collected by `/lk:scribe-harvest`
and admitted after a grill on the harvest issue.

- **These are messages to an agent, not to a person.** They are evidence for Registers 2 and 3
  only: how he joins clauses, where his ellipses fall, which markers he reaches for when he types
  fast.
- **They are not a fifth register.** `lk:scribe` never drafts text for an agent, so nothing here
  is a target form. Read them for rhythm and markers, then draft in Register 2 or 3.
- **The file holds at most 30 samples.** A harvest that proposes a sample when the file is full
  names the sample it replaces.

Each sample keeps Liam's words. A private noun in it is replaced by a generic noun in square
brackets, for example `[a component]`.
