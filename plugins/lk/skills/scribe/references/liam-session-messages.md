# Session messages — what Liam types to an agent

Messages Liam typed by hand to an agent in a Claude Code session, collected by `/lk:scribe-harvest`
and admitted after a grill on the harvest issue.

- **These are messages to an agent, not to a person.** They are evidence for Registers 2 and 3
  only: how he joins clauses, where his ellipses fall, which markers he reaches for when he types
  fast.
- **They are not a fifth register.** `lk:scribe` never drafts text for an agent, so nothing here
  is a target form. Read them for rhythm and markers, then draft in Register 2 or 3.
- **The file holds at most 30 samples.** A harvest that proposes a sample when the file is full
  names the sample it replaces.

Each sample keeps Liam's words. A private noun in it is replaced by a generic noun in square
brackets, for example `[a component]`.

## Samples

1. *"i rarely use this for casual text like [a chat app] for instance... main usage is pr comments... slack/teams messages... issues comments... tickets comments.... i mean comments in general for my work where i will appear..."*
   A list joined by ellipses, with no commas and no "and", then `i mean` to restate the list as one idea.
2. *"ok... agree but a difference from the type those banks can be used randomized from its creation... whereas typos need a filter first... you know what... lets remove the typos from this desing... lets leave that for another point"*
   He agrees, raises an objection, and reverses his own position inside one message, with `you know what...` at the turn.
3. *"if it doesnt harm to add some kind of extra register then its ok id say... (see i just used "id say") now..."*
   A parenthetical that comments on his own sentence as he types it. The sample files hold self-deprecating parentheticals, not this self-observing kind.
4. *"i want to add a new skill... hope is small and a good idea... happens that a lot of the time i discuss with you on my sessions and there is where i actually write by hand a lot of stuff... like now... me explaining this idea..."*
   How he starts a long explanation: the ask first, then short clauses with no subject, each closed by an ellipsis, before the detail.
